# scroll-stitch

スマホの画面録画（スクロール動画）を1枚の縦長PNGにつなぐツール。HTML1枚で完結し、動画はブラウザの外に出ません。

- 固定ヘッダー/ナビバーの切り落とし（プレビュー上でドラッグ）
- 行ったり来たり・停止・フリックに対応（各コマを既知の文書全体に対して位置合わせ）
- canvas上限を超える場合は自動で分割し、zipでまとめて保存

## 使い方

`index.html` をブラウザで開く。GitHub Pages 上ではそのままURLで使えます。

## 対応形式

ブラウザが再生できる動画（mp4/H.264, webm）。iPhone の HEVC(.mov) は Safari で開いてください。
